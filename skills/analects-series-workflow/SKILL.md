# 陪仲仲读《论语》协作流程

本技能保存本系列已确认的长期偏好，不把过去某次授权扩展为新一期的自动发布授权。用户本次指示优先；只收到新录音时，开始分析策划，先给方案审核。用户已确认方案并要求制作时直接执行，不重复询问固定偏好。

## 先恢复本期状态

先确定用户当前项目根目录，再读取存在的本地文件（首次使用不存在时，按本技能建立配置，不要求原作者的本机文件）：

- `项目根目录/AGENTS.md`。
- `项目根目录/series-assets/视频制作标准.md`。
- 同目录 `系列默认配置.json`，用于固定照片、圆形蒙版、片尾和参考工程的实际路径。
- 本期策划、剪辑清单、交付复核和发布台账。不能仅按修改时间选最终稿；用户后续修改与已核验的实际音轨优先。

这些早期文件有旧默认：海外文案以繁体中文配适量英文；抖音、B站、喜马拉雅默认横版；多章一章一集；开场招呼和无意义口头禅按后述最新偏好处理。不要让旧平台表或首期示例覆盖后来的确认。

按工作阶段读取 [制作与验收](references/production.md)。实际剪辑用已安装 `ffmpeg-skill`；字幕工作用 `video-subtitle-translator`；封面生成或编辑用 `imagegen`，首次使用相应技能按其要求说明。复用现有本地工程，避免从零重建已成型版式。

## 策划、制作、审核

1. 完整听录音并转写，区分爸爸和仲仲，核对篇章、原文、讲解、姓名和译名。按章拆成独立视频，不把每章压成任意时长的短片。
2. 每章给出短标题、真实原声钩子、说话人和原录音起止时间、删留及校订方案，供用户审核。没有听清就如实标出，不编造录音台词或时间码。
3. 标题短、有问题感、有继续观看的理由，温和厚重，面向重视家庭教育和品格培养的家长。引用孩子的话必须真实；趣味标题不伪装成孔子原话或历史定论。
4. 钩子优先孩子天真、可爱、有反差的真实声音。爸爸接话只有增加吸引力、必要闭环或用户指定才保留；不提前回答悬念。保留“哦”等有表现力的尾音，不能截断一句话。约5—10秒是参考，语义完整优先；不要把慢诵读强行放开头。
5. 用户确认后制作横版和竖版、封面、字幕和两种微信文案；先交审核，未获本期发布指示不上传。用户后来修改时同步全部相关画幅、字幕、时间码和独立封面，清楚标明替代的旧版本。

## 长期制作偏好

- 完整真实亲子交流，正文保留钩子所来自的讨论；钩子是预告。保留孩子举例、历史联想、分歧、纠正过程和可爱的语气。
- 默认去掉爸爸开头“同学们好／大家好”；保留或复用当次有内容的欢迎开场。清理爸爸无实义的“是不是、对不对、是吧、是吗”和卡壳犹豫，不删有语义作用的真实问句、孩子原话或改变观点的回应。必须复听实际剪后音轨，字幕搜索不能证明已经清理干净。
- 删“两句之间”的内容时，默认保留两句锚点；记录清楚包含/排除边界。用户指定时间码以指定源文件为准，先确认是否为原录音或某版成片。
- 错误知识不通过删除整段讨论掩盖。区分逐字字幕、错别字校正、独立中英校订说明、补录替换；不把修正字幕称作已修正原声。未经核准的模糊病名、人名等不猜填；若用户要求保留未辨清，保留原声并注明。
- 新补录以最新指定录音替代旧补录；匹配响度、音色、音高感、底噪与空间氛围，接缝自然，保留周边孩子回应；不过度变调或伪造声音。
- 中文原声，完整简体中文与英文字幕；仲仲 / Zhongzhong、爸爸 / Dad、孔子 / Confucius、《论语》 / the Analects。重点复核英文语法、称呼、儒家概念、人名和书名。海外发布文案用繁体中文配适量英文，不自动把成片字幕全改繁体。
- 默认免费开源本地工具；收费API、试用收费导出不采用。本系列原协作允许内置图片编辑制作封面；其他使用者须依据自己的工具偏好与授权配置，不推定付费服务授权。

## 固定外观及交付

沿用首期完整双语封面模板：米色顶底栏、深绿说明与英文、暖金书房、父子自然融合、黄白两行粗重飞白破锋毛笔主标题与不规则黑描边。参考固定素材里的 `双语封面版式参考_首期16.png` 和 `封面字体风格参考.png`。用户否定过 Ma Shan Zheng，不用普通行楷冒充同款，也不声称识别出原字库。

- 顶栏“父子共读 · 真实对话”，底栏对应英文标题及“Zhongzhong Reads the Analects”。正文和英文用清晰字体。保留完整脸部，圆形父子蒙版放右上方，边缘自然，无模糊光晕。封面与视频内开头必须同步，不能叠两段封面。
- 每章基础交付：16:9视频1920×1080、9:16视频1080×1920、4:3封面1600×1200、3:4封面1200×1600，并为横竖开场提供对应封面。平台另需9:16、16:9、方图等按入口重排，不拉伸或硬裁文字。
- 画面鲜明、字号偏大；暖米色底、深绿字；孩子黄色对白、爸爸绿色对白，突出当前句并保留上下文。横版重新排版，不缩小竖图加黑边充数。
- 每集：封面约1.2秒 → 原声钩子 → 有内容的欢迎 → 本章完整对话 → 父子告别 → 固定欢快双语关注片尾。无合适告别时复用第16章收尾原声并重排本章字幕，不能只有关注动画漏掉父子“拜拜”。
- 交付MP4、对应封面、中文/英文/双语SRT、剪辑和校订说明、朋友圈与视频号文案；按授权平台分别文件夹交付。提供可点击的绝对路径及审核入口，不能只给脚本。喜马拉雅按需求另附MP3。

## 发布衔接与续做

获明确发布指示后，读取 `../analects-series-publish/SKILL.md`，按平台、章节与当前账号状态执行。先查重；不要把 Instagram 与其 Reels 重复发两次。如用户停用某平台，未明确恢复前不发、不跨平台同步；首次使用按当前授权确定平台。

有原创/自制声明就选；没有则记录未提供，不假称已选。通用自主声明按“无需标注”；独立AI素材披露与原创权属分开，依据实际素材和页面要求，不把真人录音说成AI配音。必要差异要在发布结果中说明。

暂停就停止，继续就从本期记录恢复。制作、上传、审核、公开、定时、受限分开记；只报告实际完成结果，不把承诺的后续工作当作已经安排的后台任务。
