# 亲子共读《论语》视频协作 Skills

将真实亲子录音整理为逐章视频，并按平台分别交付和发布的协作流程。内容来自长期实际制作中的反复审核与修订。

## 包含的技能

|技能|用途|
|---|---|
|[analects-series-workflow](skills/analects-series-workflow/SKILL.md)|完整听录音、一章一集、原声钩子、口头禅清理、补录融合、中英校订、双语封面、横竖版交付|
|[analects-series-publish](skills/analects-series-publish/SKILL.md)|按目标平台适配、查重、原创与来源声明、合集、同步、排期和真实发布状态核验|

## 使用

把 `skills/` 下两个文件夹放入支持 SKILL.md 的助手技能目录；例如本机 `~/.codex/skills/`。随后可这样提出任务：

> 请用 $analects-series-workflow 处理这份录音，按章拆分，先提交标题、真实原声钩子与剪辑方案审核。

> 请用 $analects-series-publish 把我确认的第X章发布到指定平台，先检查是否发过，分别核验结果。

参考 [配置示例](config/series-config.example.json)，在自己的项目配置姓名、模板、圆形蒙版、片尾和平台。可将示例另存为自己项目的 `series-assets/系列默认配置.json`，路径按本机实际文件填写。已有制作标准可放在 `series-assets/视频制作标准.md`；首次没有这些文件时直接根据技能内容与用户偏好建立，不需要原作者文件。示例名称与风格可以替换；不会取得原作者账号或素材的使用权限。

## 需要的工具和素材

- 这是协作指令与经验包，不是开箱即用的自动剪辑软件，不包含转写模型、FFmpeg、浏览器运行环境或第三方技能的安装文件。
- 制作时可使用本机 FFmpeg、转写及字幕工具；技能中提及 `ffmpeg-skill`、`video-subtitle-translator`、`imagegen`，需要由使用者另行安装或选择可用替代工具。默认偏好免费开源本地工具；封面内置图片编辑依据使用者自己的授权配置。
- 发布流程原实践使用 ego lite；安装与可用性由使用环境决定，操作前读取其当前使用指南。
- 请自行提供有权使用的录音、人物图片、封面参考和片尾。仓库不含父子照片、孩子真实录音、视频成片、账号、登录凭据或私人发布记录。
- 逐章方案先审核，实际发布另需用户授权；技能本身不是自动发布许可。原创权属与平台AI素材披露分别处理。

平台比例和界面说明是制作选择与经验，不保证所有账号、入口永远一致。发布前检查实际槽位、安全区域和当前上传限制。
